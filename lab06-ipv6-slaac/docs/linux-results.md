# 实验六 Linux SLAAC 实测

2026-11-22，WSL2 Linux 命名空间，radvd。五个阶段均有终端记录。

| 阶段 | 实测 |
|---|---|
| PC1 基线 | 自动生成 3001::/64 地址，默认下一跳 fe80::a1，Ping R1 2/2 |
| RA 参数修改 | 默认路由 hoplimit 64 → 32，剩余寿命 1798 → 899 秒，Ping R1 2/2 |
| 仅 R1 | R3 自动生成 2000::/64 地址，默认路由经 fe80::1 |
| 双 medium | 两条默认路由，查询离链目标选 fe80::1 |
| R2 high | 两条默认路由仍在，同一目标改选 fe80::2 |

B 链路三个阶段均对在链路内的 R1 Ping 2/2。离链选择由 route get 验证。Reachable Time、Retrans Timer 和报文字段需对照抓包。华为原生、VMnet8 和两项附加安全实验待验证。
