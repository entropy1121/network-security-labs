# 课堂实验五：IPv6 邻居发现协议（公开版实验记录）

> 本文为去除个人身份信息后的公开实验记录，不替代课程正式提交的 Word 报告。实验结果分平台陈述，未完成的部分不作为已完成项目。

## 实验目标

观察邻居发现协议（Neighbor Discovery Protocol, NDP）中的地址解析、重复地址检测、邻居可达性跟踪及其在虚拟网络环境中的实际表现。结合 VLAN Trunk、静态邻居项与受控安全实验，分析地址到链路层地址的映射如何影响 IPv6 通信。

## 实验环境与实现差异

首先使用 GNS3 中的华为 CE12800 虚拟设备配置 VLAN100、VLAN200、Trunk 和 Vlanif 地址。华为工程可执行相关命令，但实际端到端单播测试未成功。为区分协议实现与实验环境的问题，随后用 GNS3 自带 Ethernet Switch、VPCS 构建独立拓扑验证二层转发，并在隔离 Linux Namespace 中观察 DAD、NUD、静态邻居和安全测试。三种平台的结果不能互相替代。

## 地址解析

GNS3 内置交换机工程在 VLAN100 内配置 PC1（`2000::1`）、PC2（`2000::2`），在 VLAN200 内配置 PC3（`3000::3`）、PC4（`3000::4`）。四个方向分别发送 3 个 Echo Request，全部收到回复。

Wireshark 中，PC1 首先发送 ICMPv6 Type 135 的 NS：IPv6 源地址 `2000::1`，目的地址 `ff02::1:ff00:2`，Target Address `2000::2`；以太网目的 MAC 为 `33:33:ff:00:00:02`。PC2 随后发回 Type 136 的单播 NA，将 `2000::2` 通告为 `00:50:79:66:68:01`，报文中 Solicited 和 Override 标志均为 1。反方向也观察到 NS/NA。此过程说明 IPv6 借助请求节点组播和邻居通告完成链路层地址解析。

## DAD 与邻居状态

Linux Namespace 中，新地址没有冲突时能够启用；当另一节点已持有相同地址时，新的地址出现 `dadfailed tentative`。DAD 所用 NS 的源地址 `::` 与正常地址解析时的源地址不同，因而可以从报文中判断其用途。

邻居表中，正确的永久映射保证通信，错误 MAC 使两次 Ping 均超时；删除错误项后，重新通过邻居发现机制获得正确映射，通信恢复。观察过程中真实记录到 `REACHABLE`、`DELAY` 和 `INCOMPLETE`，但没有记录到 `STALE` 和 `PROBE`，故不把后两者写为完成。

## VLAN Trunk 与任意播

在已验证的 GNS3 工程中，PC5、PC6 接入两台交换机的空闲端口，使 VLAN100 与 VLAN200 的测试通信都必须通过交换机间的 Trunk。四组跨交换机双向 Ping 均为 3/3，Trunk 抓包中两种 VLAN 标签各出现 16 帧，接入端口抓包未见标签；这一点与配置的 Access / Trunk 机制相符。

在独立临时 Linux 路由模型中，两台节点共享 `3888::/128`。先选择 SWA 路由，再改走 SWB 路由，两阶段 Ping 都是 3/3。第二路径 PCAP 只抓到 2 对请求/响应，因此分析以路由选择和通信成功为主，不夸大抓包覆盖度。该实验不等同于华为 CE12800 的原生命令复现。

## 安全测试和故障排查

在受控的 Linux Namespace 中，NS 相关的邻居缓存污染得到观察，NA 欺骗及 DAD 干扰未能确认预期效果。未成功的测试保留原始输出，以免只展示正向结果。

CE12800 实验中，MAC 表能够学习本地 PC，且部分组播 NS 能抵达对端，但单播 NA 不能可靠返回；后续 IPv4 单播对照也失败。相同 GNS3 服务上，内置交换机的 IPv4 和 IPv6 均正常，因此故障更集中于原华为虚拟数据平面的配置或实现，仍不能仅凭这些信息确定具体根因。

## 实验总结

这次实验中，正常 Ping 只是起点。真正能解释通信过程的是把邻居请求、通告、缓存状态和链路层转发对应起来。静态邻居映射实验也说明，地址配置正确并不能保证通信；只要目标 IPv6 对应的 MAC 错误，发出的单播帧就无法到达目标。排查华为工程时，起初容易把 Ping 失败理解成 IPv6 配置错误，但后来的 IPv4 对照与两端抓包表明，问题需要放在实际二层转发链路中定位。另一点是需要分清实验平台的能力边界：Linux 与 GNS3 内置交换机证明了相应协议机制，而华为原生数据转发未通过的事实应单独保留。这样的记录比简单地把所有步骤写为成功更能反映真实实验过程。
