# Lab04 验证记录（依据用户真实终端输出）

## 地址与主备
- VLAN10：R1=10.44.10.2，R2=10.44.10.3，VIP=10.44.10.1 / 10.44.10.254
- VLAN20：R1=10.44.20.2，R2=10.44.20.3，VIP=10.44.20.1 / 10.44.20.254
- R1 初始持有两条 .1 虚拟 IP；R2 初始持有两条 .254 虚拟 IP。

## 故障前后
1. 正常：PC1-4 各 Ping 2/2，0% loss。
2. ISP1 WAN Down，7 秒后：R1 无 VIP，R2 四个 VIP；PC1-4 各 2/2，0% loss。
3. ISP1 恢复，7 秒后：R1 .1 两组，R2 .254 两组；PC1-4 各 2/2，0% loss。
4. ISP2 WAN Down，7 秒后：R1 四个 VIP，R2 无 VIP；PC1-4 各 2/2，0% loss。
5. ISP2 恢复，7 秒后：R1 .1 两组，R2 .254 两组；PC1-4 各 2/2，0% loss。

## 证据性质
终端真实输出由用户在对话中提供，GitHub 此处是**结果摘录**，不是直接读取了用户 WSL 上的原始日志。首次 ISP1 故障测试运行成功，但普通用户 tee 写入 evidence/04_isp1_failover.txt 被拒绝；ISP2 使用 sudo tee 成功保存。本仓库没有伪造或上传不存在的原始截图。

**测试限制：**只验证故障稳定后连通性，没有测量中断时长或保证切换过程无丢包。
